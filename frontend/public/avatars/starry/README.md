Add `waving.png`, `studying.png`, `sleeping.png`, and `gaming.png` sprite sheets here. Each sheet should use the 4-column by 2-row grid described in `animations.json`.

Starry also has gesture sheets: `walking.png`, `jumping.png`, and `leaving.png` (the last one is split into the `leaving` and `waveGoodbye` clips). They were packed from `art-source/starry/gestures-source.jpg` with `npm run sprites:pack`; `art-source/starry/NEW-ANIMATIONS.md` explains how. If a gesture sheet is deleted, she falls back to her waving frames.

# Crystal runtime sprites

Gesture sheets use the transparent 1536 × 1024, 4-column × 2-row grid described in `animations.json` (384 × 512 per frame).

- `walking.png`: eight frames, loops at 10 fps.
- `jumping.png`: eight frames, plays once at 11 fps.
- `leaving.png`: frames 0–4 for getting up; frames 5–7 for the doorway goodbye.

Click the character to jump. Set the routine to “After 1 min studying” to preview leaving and walking. Original gesture sheets and extraction instructions are in [art-source/crystal](../../../art-source/crystal/README.md).
